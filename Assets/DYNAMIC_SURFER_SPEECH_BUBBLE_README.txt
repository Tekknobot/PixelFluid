DYNAMIC SURFER SPEECH BUBBLE PATCH

SurferSpeechBubble now rebuilds its pixel bubble for every displayed line.

- Text wraps at word boundaries.
- Long words split safely.
- Font size shrinks only when needed.
- Bubble width and height are calculated from the rendered TextMesh bounds.
- Padding and the pixel tail resize with the message.

Inspector controls on SurferSpeechBubble:
- Preferred Font Size
- Minimum Font Size
- Maximum Characters Per Line
- Maximum Bubble World Width
- Horizontal / Vertical Padding Pixels
- Outline Pixels
- Tail Height Pixels

No prefab or TextMeshPro package is required.
