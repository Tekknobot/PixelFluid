SURFER SLUG - WAVE SWITCH JUMP COMBO

Player controls changed in TinyWaveSurfer.cs:

Keyboard
- Space: normal trick jump on the current wave
- Hold W / Up Arrow + press Space: trick-jump to the wave above
- Hold S / Down Arrow + press Space: trick-jump to the wave below

Controller
- A: normal trick jump on the current wave
- Hold D-pad Up + press A: trick-jump to the wave above
- Hold D-pad Down + press A: trick-jump to the wave below

Up/Down alone no longer changes waves.
A/Space must be released before another jump or wave switch can trigger.
D-pad Left/Right and Left Stick still control horizontal movement.
