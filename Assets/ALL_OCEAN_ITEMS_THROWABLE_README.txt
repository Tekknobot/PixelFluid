SURFER SLUG - ALL OCEAN ITEMS THROWABLE

- Every automatically collected ocean item is now added to one shared throwable inventory.
- Each item keeps its own sprite while stored and uses that sprite when thrown.
- Items are thrown in the same order they were collected.
- Existing soda-can pickups also enter this inventory.
- Action throws toward nearby sharks/squid.
- Hold Up + Action throws the next item at the UFO.
- The compatibility property SodaCanCount now reports the total number of all stored throwable items.
