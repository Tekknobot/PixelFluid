FLOW FINISHER: THREE-LANE WATER DREAM VERSION

Controls
- Right Bumper / R while riding: Water Slash
- Right Bumper / R while ON FIRE and riding: Flow Finisher

Changes
- Flow Finisher now releases up to three piercing water slashes across the nearest simulation lanes.
- The current lane is always included. Adjacent lanes are selected without wrapping across the full stack.
- Each projectile is positioned on its own simulation's live gameplay surface.
- Each projectile uses that simulation's render queue so it appears in the correct lane depth.
- Projectile colour is blended toward the target simulation's rendered main/surface water colour, including independent-layer shading.
- Normal Water Slash default scale reduced to 0.72 x 0.72.
- Each Flow Finisher slash default scale reduced to 0.92 x 0.92 (previously 1.65 uniform scale).
