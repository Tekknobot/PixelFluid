SURFER SLUG - PLAYER CONTROLS PATCH

Keyboard
- A / D or Left / Right: steer
- Space: jump / start air trick
- W / Up: move one wave toward horizon
- S / Down: move one wave toward foreground
- Left or Right Shift: boost
- Q / E while airborne: add counter-clockwise / clockwise trick rotation
- F / X: throw soda can (existing action)
- Z: cinematic camera (existing action)

Xbox / Standard Gamepad
- Left Stick: steer with analog acceleration
- A / South Button: jump / start air trick
- D-Pad Up or LB: move one wave toward horizon
- D-Pad Down or RB: move one wave toward foreground
- Right Trigger: boost
- Right Stick Left / Right while airborne: add trick rotation

Space previously triggered TinyWaveSurfer.BeginTurnTrick(). This patch keeps that action,
but adds acceleration/deceleration, analog movement, air steering, a smoother jump arc,
and player-controlled trick rotation.

Tune in TinyWaveSurfer Inspector under:
- Player Movement Feel
- Player Air Tricks
- Edge Turn Trick
