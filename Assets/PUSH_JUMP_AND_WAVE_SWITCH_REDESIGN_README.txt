SURFER PUSH JUMP + WAVE SWITCH REDESIGN

- Jump during an active charged-skid push always starts the forward surf jump.
- No regular standing trick jump or wave switch can occur during the push.
- Forward input is not required because the active push direction supplies takeoff direction.
- Push momentum is converted once into launch distance, then the skid state stops.
- Every wave switch plays chuck_wave_switch.
- Wave switching no longer rotates, flips, or tucks the surfer transform.
- Wave-switch arc is lighter and lower.
- The runtime Resources animator controller now includes chuck_wave_switch.
- chuck_wave_switch is configured as a one-shot clip.
