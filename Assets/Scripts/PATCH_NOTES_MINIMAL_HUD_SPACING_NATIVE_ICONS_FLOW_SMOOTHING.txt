Surfer Slug Minimal HUD spacing/native icon patch

- Rebalanced the top status bar so vitals, day/time, and inventory share space evenly.
- Reduced text sizes where needed and enabled safe auto-sizing for long time/distance and objective text.
- Objective remains one line and now truncates with an ellipsis instead of overflowing.
- All HUD icons and throwable item sprites use their native pixel dimensions.
- Missing HUD icon resources are hidden instead of showing Unity's default white rectangle.
- Inventory slots are larger but do not resize the item artwork.
- Flow meter now eases upward and downward instead of snapping when flow increases.
- Flow percentage displays the smoothed meter value.
