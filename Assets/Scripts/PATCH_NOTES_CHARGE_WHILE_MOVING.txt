CHARGE WHILE MOVING

All previous combined changes remain intact.

New:
- Chuck can keep moving and steering while holding skid charge.
- Charging no longer automatically forces horizontal velocity to zero.
- Movement remains slightly slower and less responsive while charging so the
  action still feels committed.

Defaults:
Allow Movement While Charging: true
Charging Movement Multiplier: 0.72
Charging Acceleration Multiplier: 0.62
